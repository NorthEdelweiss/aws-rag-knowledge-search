# sample_docs — RAG 動作確認用の架空文書

すべて **Claude が生成した架空の社内文書**（サンプル株式会社）。実在の企業・顧客・法令運用とは無関係で、
実務で扱ったファイルは一切含まない。

| ファイル | 想定用途 | 「文書にしか無い答え」テスト例 |
|---|---|---|
| `01_電気設備_定期点検マニュアル.md` | 設備分野 | 「年次点検はいつ、誰が実施する？」→ 毎年十月・外部の登録点検業者 |
| `02_テレワーク勤務規程.md` | 人事規程 | 「在宅勤務手当はいくら？」→ 1日200円・月上限3,000円 |
| `03_経費精算ルール.md` | 経理ルール | 「経費の申請期限は？」→ 翌月5営業日まで |
| `04_ナレッジ検索システム_運用手順.txt` | システム自身の運用（.txt 形式の確認も兼ねる） | 「取込は何文字ごとに分割？」→ 約500文字・80文字重ね |

反向テスト（文書に無い質問）例: 「有給休暇は年何日？」「会社の設立年は？」→ 「資料内に該当情報が見つかりませんでした」と返るのが正解。

S3 へは `aws s3 sync sample_docs/ s3://<文書バケット>/docs/ --exclude README.md` で配置する。
